# 02: 锚点探针——消息区能不能从像素里认出来

**What to build:** 从一帧里推导出 `ChatPane`（消息列表区）的矩形，规则必须由
**像素内容锚定、不写死坐标**，同一份代码要同时吃深色主题、浅色主题、
125%/150% DPI、任意窗口尺寸。

命令打印推导出的矩形和推导依据（面板底色是什么、从哪条边推出来的、输入框顶边
在哪），并把带框的图存盘供肉眼核对。

推导失败（窗口太小、拖动中布局没铺好）必须返回"认不出"并让上层重试，
**不能猜一个默认值**。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] `cargo xtask probe layout` 在微信窗口上打印出 `ChatPane` 矩形和面板底色
- [ ] 同一个窗口在深色主题和浅色主题下都能推出同一个矩形位置
- [ ] 125% 和 150% DPI 下都能推出正确的矩形，且不是把 DPI 当成坐标缩放
- [ ] 窗口拖动、缩放后重跑命令仍能推出矩形，不需要重启
- [ ] 窗口窄到一定程度时返回"认不出"，而不是推出一个明显错误的矩形
- [ ] 带框的输出图存盘，肉眼能看出框正好贴着消息区上下边界，
      没有切到输入框或切掉最后一条消息
- [ ] 同一逻辑布局在 100% 和 150% DPI 下推出的**逻辑坐标**一致（物理像素不同）
