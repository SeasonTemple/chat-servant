# 03: OCR 探针——中文能不能认出来、说话人能不能分

**What to build:** 在抓到的帧上跑本地离线 OCR，把每个识别框归类成
`Me` / `Them` / 噪声，并画出彩框存盘。

要回答两个只能实机回答的问题：
1. `Windows.Media.Ocr` 在这台机器上认不认中文（依赖系统语言包，装没装只有跑了
   才知道）。认不出必须明确报错并指出缺语言包，不能静默返回空。
2. 微信气泡颜色规则在**当前微信版本**上成不成立（参考项目锁的是它当时的版本）。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] `cargo xtask probe ocr` 打印每一行的文本、置信度、以及归类结果和**归类依据**
- [ ] 存盘的彩框图能一眼看出哪句是对方说的、哪句是我发的
- [ ] 消息区里的时间戳、引用块、群里的发言人名、链接卡片**没有**被当成消息
- [ ] 表情包/头像/图片里的文字**没有**被当成消息
- [ ] 同一个气泡里的多行文字被合并成一条 `Message`，不是拆成三条
- [ ] 识别引擎在系统缺对应语言包时，报一个说清楚"缺什么、去哪装"的错误
- [ ] 命令打印单帧 OCR 耗时
- [ ] 颜色/对比度阈值改动后，重跑命令能看到归类结果随之变化的对比输出
