# 06: 增量识别——静止零开销，新消息只读新增带

**What to build:** 用户能观察到的行为是：**聊天窗口静止时，一次 OCR 都不跑**；
对方来新消息时，只识别新增的那一段，不是把整个聊天区重读一遍。

维护一条"已提交水位线"。新消息永远从底部出现，所以只需要对水位线以下的
新增带做识别，已识别的部分不重跑。

变化门控只比较 `ChatPane` 区域，**必须排除会自己动的元素**——置顶公告条会滚动，
把它算进 diff 会导致画面永远停不稳（参考项目已经踩过这个坑）。

回读验证：用一组夹具帧回放，统计 OCR 被调用了几次。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 回放一组静止帧，OCR 调用次数为 0
- [ ] 回放一组只在底部新增消息的帧，每条新消息只触发一次增量识别
- [ ] 顶部有滚动置顶公告的帧，不会导致"永远判定为变化"
- [ ] 滚动翻出旧消息不算新消息，不触发增量识别
- [ ] 切走再切回同一会话，已识别的消息不重复上报
- [ ] 识别失败时不推进水位线，下一帧会重试而不是永久丢消息
- [ ] 调试视图能看到"这一帧识别了多少像素 / 调了几次 OCR / 多少视觉 token"
