# 07: 语义遮罩与尺度归一——遮罩求准，缩放求省

**What to build:** 两件不同性质的事，必须分别验收：

- **语义遮罩（准确率优先）**：把头像、表情包、图片里的文字、时间戳、引用块、
  发言人名、链接卡片、置顶公告、系统提示从图里抠掉。首要目标是
  **不把这些误当成对方说的话**，省成本只是副作用。
- **尺度归一（成本优先）**：按 DPI 归一到逻辑布局，再按 token 预算缩放。
  大图缩到预算内，小图不盲目放大。

用户能调的"识别精度 / 成本"滑块，底层是一个**可以用 token 直接换算**的数字，
不是"高/中/低"的模糊标签。

明确不做：高斯/双边模糊、二值化、锐化后再放大、去色/直方图均衡、
形态学开闭做文本行分割。这些对神经 OCR/VLM 是负收益或零收益。

**Status:** 语义遮罩 done / 尺度归一 未开工

## 语义遮罩：验收标准是准确率，不是成本

ADR-0002 第 3 级是五级里**唯一**以准确率为主的一级。
用成本指标衡量它，会把它优化成一个纯粹的省钱步骤，
而它真正的价值在「不把头像里的字当成对方说的话」。

落点 `crates/perceive/src/mask.rs`，接缝是
`pipeline::read` 里的 `reject_image_text` —— **只改说话人，不改其他判据、
不重排行序**。

## 实测数据推翻了「只看众数占比」

用 `scripts/colors.ps1` 在真实帧 `target/probe/text-chat.png` 的
聊天图片区域（140×160 = 22400 px）实测：

| 区域 | 众数占比 | 精确色种数 |
|------|---------|-----------|
| 我方气泡 `rgb(114,205,144)` | 1.00 | 1 |
| 面板底色 `rgb(30,30,31)` | 1.00 | 1 |
| 对方气泡 `rgb(47,47,48)` | 1.00 | 1 |
| **聊天里的图片** | **0.51** | **2037** |

**图片区有 51% 的纯黑背景**，众数占比高得离谱。
按「众数占比 < 45% → 图内字」这条参考项目继承来的规则，
这张图会被判成平表面，图里的字直接进 `Message[]`。

所以主判据必须是**精确色种数**（阈值 6），众数占比只当第二道保险。
纯度那道保险在本例上确实没用——但它在「三色渐变背景占比 0.9」那种
情况下有用，两者都要。

这两个数字被写进 `the_measured_photo_numbers_are_recorded_here`
并断言它们之间的关系：将来谁把主判据改回「只看占比」，
或者把纯度阈值调到 0.6 以上想「更严」，测试会立刻指出
真实帧上那个 0.51 本来就高于任何合理的纯度阈值。

## 对比度绝不能当「图内字」的判据

实测对方气泡正文对比 **178.4**，高于标题阈值 140，也高于任何
「这是图片里的字」的合理对比阈值。拿它当判据会把对方说的话判成图内字——
**把整个对话判没了**。

`contrast_alone_can_never_mean_image_text` 把这条钉死。
