# 07: 语义遮罩与尺度归一——遮罩求准，缩放求省

**What to build:** 两件不同性质的事，必须分别验收：

- **语义遮罩（准确率优先）**：把头像、表情包、图片里的文字、时间戳、引用块、
  发言人名、链接卡片、置顶公告、系统提示从图里抠掉。首要目标是
  **不把这些误当成对方说的话**，省成本只是副作用。
- **尺度归一（成本优先）**：按 DPI 归一到逻辑布局，再按 token 预算缩放。
  大图缩到预算内，小图不盲目放大。

用户能调的"识别精度 / 成本"滑块，底层是一个**可以用 token 直接换算**的数字，
不是"高/中/低"的模糊标签。

明确不做：高斯/双边模糊、二值化、锐化后再放大、去色/直方图均衡、
形态学开闭做文本行分割。这些对神经 OCR/VLM 是负收益或零收益。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 送进识别的区域里不含头像、表情包、时间戳、引用块、发言人名、
      链接卡片、置顶公告
- [ ] **准确率验收**：夹具里头像、表情包、图片内的文字**都没有**出现在
      `Message[]` 中（这是本 ticket 的首要验收点，不是成本）
- [ ] 遮罩规则里**颜色是判据**，所以管线在这一步之前不做去色
- [ ] 每个被丢弃的区域带着丢弃原因和判定依据，供调试视图消费
- [ ] **成本验收**：滑块改动后，送识别的视觉 token 数按预算变化，
      且界面上显示具体数字
- [ ] 100% 和 150% DPI 下，同样的逻辑布局送去识别的 token 数相同
- [ ] 在滑块最低档，重要对话仍能识别出消息文本；最高档不出现"越大越差"
- [ ] 缩放用 `image` crate，不自己实现重采样算法（见 ADR-0003）
