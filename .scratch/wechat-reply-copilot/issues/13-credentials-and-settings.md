# 13: 凭据与设置——key 不落文件、不进日志

**What to build:** 用户在设置页填模型 key，程序能从凭据处读到它去调模型，
但**任何文件里都不出现 key，任何日志里都不出现 key**。

设置改动即时生效不用重启。已配置的 key 输入框留空 = 保留，
用户不想每次改别的设置都重新粘一遍。

前端拿不到 key，也不需要知道模型路由——所有网络调用在 Rust 侧。

**Blocked by:** 12

**Status:** ready-for-agent

- [ ] key 存进 Windows 凭据管理器（或环境变量），仓库和配置目录里 grep 不到
- [ ] 所有错误文本经过脱敏，含 key 的上游报错不会原样显示或写入日志
- [ ] 设置改动下一次生成立即生效，不用重启
- [ ] 已配置时 key 输入框留空 = 保留原值，不清空
- [ ] 前端拿不到 key：前端代码里没有任何一处能读到 key 本身
- [ ] 前端不发起网络调用，所有出网都在 Rust 侧
- [ ] 配置里切换模型供应商时，只需填一把新 key，不需重配整个应用
- [ ] 缺少 key 时给出明确的下一步指引，不是一个空列表或静默失败
