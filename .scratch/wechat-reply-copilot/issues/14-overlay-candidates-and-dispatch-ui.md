# 14: 悬浮窗候选卡片与档位切换

**What to build:** 用户能看到的核心交互：对方来消息 → 面板给出判断摘要 + 三条候选
（带概率、推荐条置顶）→ 点一下填进输入框 → 可选"确认后发送"。

面板贴在聊天窗口旁边，可拖可缩、永远置顶，窄的时候自动进紧凑模式。
底部能展开实时聊天记录，认错了要能立刻发现。
独立调试窗口用彩图画出每个识别框——我 / 对方 / 被过滤 / 发言人名 /
当成图片丢掉 / 小字丢掉。

**Blocked by:** 09, 12, 13

**Status:** ready-for-agent

- [ ] 对方来新消息时面板更新：判断摘要 + 三条候选，按概率排序，推荐条置顶并标注
- [ ] 点"填入"→ 文本进输入框并停下；点"确认发送"→ 二次确认后发送
- [ ] 档位切换：三档可见，默认是最低档，切回最低档是一步操作
- [ ] `Auto` 档下每条消息都可见、随时可打断
- [ ] 面板可拖可缩、置顶、不抢焦点；窄于阈值自动进紧凑模式而不是文字挤成两行
- [ ] 会话切换时面板跟着切，历史/上下文/候选不串味
- [ ] OCR 抖一下不会分裂出新会话
- [ ] 底部能展开实时聊天记录
- [ ] 调试窗口画彩框，六种颜色各代表一种归类结果，认错了一眼能定位是哪一步
- [ ] 面板宽度变化时不出现布局塌陷或文字溢出
- [ ] 前端 `.svelte` 文件通过 `svelte-autofixer` 零告警
