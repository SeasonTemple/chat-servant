# 23: 按钮组件族 —— 替掉黑底 / 红底两块毛坯

**What to build:** 面板上所有按钮从同一套组件族里出，共用一套几何。
红**不再是一整块红底**，而是页边一道 3px 竖笔。

**Blocked by:** None（可以立刻做）

**Status:** ready-for-agent · 设计稿见 `docs/设计规范.md` §4.2c

## 现状的问题

`ui/src/routes/(panel)/+page.svelte` 现有 `.cs-btn-ink`（纯黑底）和
`.cs-btn-live`（纯红底）。两个问题：

1. 两个大色块在 316px 内容栏里互相压；
2. 更要紧的是——**一整块红底把「不可逆」说成了「醒目」**。
   红应该是红笔在页边划的那一道，不是铺满的底。

## 三种变体（共用几何：高 30 / padding 0 16 / radius 4 / 13px 600 / 全是 1px 描边）

| 变体 | 用途 | 规则 |
|---|---|---|
| **墨线** | 可撤销、可逆 | 1px 墨描边 + 透明底 + 墨字；hover 墨 7% |
| **实墨** | **每屏最多一颗**，唯一主动作 | 墨底 + 纸色字 |
| **红批** | 不可逆 | 红只在页边一道 3px 竖笔（hover 5px），框与字仍是墨色 |

**因为三种都是 1px 描边，S5 的「先不发 / 发送」天然等宽等高** ——
不再需要给 ghost 补透明边框去凑那 2px。

## 落进代码时要一并处理的历史包袱

- [ ] `.cs-btn-live` 现在那条「给 ghost 补透明边框」的注释所防的 2px 差，
      **在新族里不存在了**，连同那条 hack 一起删。留着一个没有对象的注释
      会让下一个人以为还有这个坑
- [ ] 红批的红条用**绝对定位的伪元素**，不许改 `padding`。
      早先为它把 `padding-left` 加到 19px，文字整体右移 9px，看着没居中。
      **几何必须由 box 一处说了算，装饰不许改 padding**
- [ ] 「填入」在 S4 属于**可撤销**（只把字放进输入框），所以用墨线不用实墨。
      实墨留给按下去就收不回来的那一步
- [ ] 焦点环**用墨不用红**（沿用 §5.4）；禁用是 `opacity .34` 不换色

## 验收项

- [ ] 全仓 grep `cs-btn`，所有按钮都能对上三种变体之一，没有第四种
- [ ] S5 两键**实测等宽等高**（不是「肉眼看差不多」——量出来）
- [ ] 红底色块从纸面上消失：截图里红只出现在页边那道竖笔上
- [ ] forced-colors 下三态仍可分辨
- [ ] 焦点环用墨，截图存证
