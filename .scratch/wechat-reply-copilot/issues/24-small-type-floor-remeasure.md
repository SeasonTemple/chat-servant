# 24: 小字下限复测（10.5 / 11 / 12px）

**What to build:** 面板上最小的字到底能不能读，给出**实测**结论而不是保守拍脑袋。

**Blocked by:** None（可以立刻做）

**Status:** done · **2026-10-14 量具重建 + 三档数据 + 字重对照，结论已定**（小字 ≥11px、10.5 不能放、杠杆是字重 600）· **2026-10-24 真机人眼结论：读得清 ⇒ 本票结案**
（结论**与 v1 的「下限 12px」相左** ⇒ 改的是数据的使用方式，量具自检全过）

## 结论先写

1. **v1 主张的「下限 12px」不成立。** 12px 与 11px 的断笔风险**几乎一样**
   （≤1px 细笔画 75.1% vs 77~80%）。把下限从 11 抬到 12 只买来约 7 个百分点。
2. **10.5px 不能放**：82.3%，三档里最差。
3. **真正的杠杆是字重，不是字号。** 同样 11px，`font-weight` 400 → 600
   把 ≤1px 细笔画从 **~78% 压到 ~16%**——**一个字号档换 5 倍**。
4. ⚠ **`font-weight: 500` 是假的**：本机雅黑没有 500 字重，浏览器渲出来与
   400 **逐字节相同**（细笔画 79.6% / 77.2% 两档完全一致）。
   要加粗就用 600；写 500 等于没写。

⇒ **行动项**：小字维持 **≥ 11px**，**不要放 10.5**；
把常规字重的小字（归属行引文、档位名）**加到 600**。
这与票 22 的教训同向：「先加字重，不要降字号」——现在小字也量到了同一结论。

### ⚠ 量具自己踩过的五个坑（都在脚本注释里，逐条写明为什么）

1. **整图取墨 ⇒ 整页都是墨。** 工作台底色 luma **110**，比墨阈值 150 还暗。
   症状是「跑不完」+「报出来的表看起来完全正常」。
2. **先框纸再取墨。** 左侧常驻一块 380×560 的**纸样参照**，与候选带同色且更大；
   取并集就量到**空白参照纸**。⇒ 选**含墨最多**的那块纸。
3. **直接取外接框 ⇒ 桌面底色算墨。** 框里纸上缘之外是底色（luma 110），
   整块被并成**一行 96 CSS px**，「墨高÷字号」报到 9.2。
4. **纸掩码 ∧ 墨掩码 ⇒ 文字被滤掉。** 文字**替换**了纸的像素，
   求交剩 0 行。⇒ 按行**填实**纸（内部含文字处算纸）。
5. **纸纹底 ⇒ 折痕撑宽包围盒。** 纸材位图有暗折痕（最暗到 luma 26，与文字同量级），
   把「示例联系人」那行撑到 229 CSS px（真值约 60），**字面率从 27% 掉到 9%**。
   折痕与 11px 竖笔**同形同密度**，按形状与列密度都剔不掉（两条都试过）。
   ⇒ 量具**默认在纯色底上量**；要量纸纹得显式加 `--drop-isolated`，
   而那个开关在纯色底上会**误伤真字**（实测 12px「只填入」量出 23 px，
   **比 10.5px 的 31 px 还窄**）——已改成默认关闭。

### 自检（都自证过会响）

- **恰好 3 行**（归属行 2 行 + 档位名 1 行）。初版是 4 行（含撕口暗边）
  一路绿灯——现在会 abort。
- **墨高÷字号 必须在 0.5~1.2**。超出说明行切错了，或 `--scale/--size`
  与出图对不上（两者都会让「细笔画」变成另一个字号的数）。
- **ABORT 而不是空结果**：纸没渲出来、阈值吃到纸底，都必须报错退出。
  「静默返回空结果」是票 24 首轮记下的量具坑之一。

## 首轮为什么作废

字号档的文本行切分把**汉字行误并进了等宽行** —— 一个 sheet 里混排多种行，
行切分按「比纸暗」判定，等宽行的墨也进了掩码。重测时
**每个字号单独成行，且与字体实验分开**。

## 量具

用 §4.2 那套（`target/typo/analyse-type.py` 已可用）：
**字面率 + ≤1px 细笔画占比 + 墨迹高÷字号**。

⚠ **不要用「紧邻占比」** —— 它量的是笔画宽度不是字间距，
而且汉字上字间距根本不可测（列投影零区分度、连通域聚类整行聚成 1 个字）。
详见 `docs/设计规范.md` §4.2 顶部那条自我更正。

⚠ 三个已知的量具坑（脚本注释里有记，别重踩）：
纸边抗锯齿把页底灰混进掩码导致行切分退化成整块、脚本**静默返回空结果**；
渲染倍率让坐标整体错位（从纸块宽自动折回，别硬写 `scale=2`）；
一个 sheet 里混排多种行会串行。
