# 25: 主窗口加载的是被判为废弃的旧面板

**What to build:** 用户打开应用看到的是**当前**面板，不是 `(panel)/` 那张被自己判为废弃的。

**Blocked by:** None（可以立刻做）

**Status:** ready-for-human · **C 方案已于 2026-10-13 实现**（旧面板删除、
两路由共用 `$lib/PaperPanel.svelte`、窗口控制与设置搬进新面板、档位与
`readout` 接上 Rust）。三个验收项已过，**冷启动实机那一项 ⛔ 未验**，
需要本机微信在场，故留给本机那一轮。
· ⚠ 设计规范 §8.1b 与 §10 第 6 条已同步销账
· ⚠ 遗留：设置页里的档位控件仍是旧 `SegSlider`，与顶边红勾是两套形态语言 → 票 23
· **2026-10-13 补（出图自查后）**：档位行经两次挪位，最终落在纸底。
  起点是「独占顶行」（121px / 占面板 21%，红勾盖在标签上）→ 挪到归属行右侧
  → **自查发现把归属文字挤断了**（「示例联系人」折成两行，316px 栏里两枚记号
  加标签占掉 134px）→ 落到正文下方并用 `margin-top: auto` 压到纸底。
  同时：取景框 24×16 → **34×22**（勾在纸底读不出来的原因是**墨太少**，
  不是颜色不对；放大只能靠放大框，调 opacity 会把五级密度拉平）；
  窗口键从 `--cs-mark` 换 `--cs-pencil`（3.00:1 → 5.10:1）。

## 事实

`ui/src-tauri/tauri.conf.json` 的窗口 `url` 是 `/`，而路由 `/` 挂的是
`(panel)/+page.svelte` —— **那张面板在设计规范里被明确判为废弃**
（§10 第 6 条「旧面板 `(panel)/` 何时整体删除」也还挂着）。
新面板在 `/panel`。

也就是说：**默认入口指向的是一个计划删除的页面。**

## ⚠ 2026-10-13 补：两套面板并存的体量

整理文档时清点了前端规模，**这不只是「入口指错了」，是同时养着两套**：

| 路由 | 行数 | 状态 |
|---|---|---|
| `(panel)/+page.svelte` | **1553** | 判为冻结，**但主窗口加载的就是它** |
| `panel/+page.svelte` | **254** | 新面板，**只有撕边纸 + 顶边档位区，正文区故意空着** |
| `studio/+page.svelte` | 430 | 材质台（A 段纸面 / B 段圈还是勾） |
| `debug/+page.svelte` | 312 | 调试画布 |
| `ui/src/lib/*.svelte` | 1687 | 其中 `PanelSettings` 818 行最大 |

**1553 : 254** —— 旧面板是新面板的六倍。

⇒ 票 23（按钮族）与票 22（手写体）这两个纯设计票，卡住的不是「难做」，
是**不知道该做在哪块面板上**。在这张票拍板之前，
任何新设计工作都有做进废件里的风险。

⚠ 连带：`ui/src/lib/` 下 7 个组件里，`CandidateCard` / `MessageStream` /
`ReasonBar` **只有旧面板在用**。票 25 选了 C 的话，它们是跟着删还是移到
新面板——**这也是必须一起拍的一部分**，不能等路由合完再发现。

## 两个方案

- **B**：`tauri.conf.json` 的 `url` 改成 `/panel`。
  一行改动。代价是 `(panel)/` 还在树上，只是不再是入口 ——
  它连同 `PanelSettings` 等组件要不要一起留，得一起决定。
- **C**：删掉 `(panel)/`，把 `panel/` 改名成 `(panel)/`。
  路由不变，入口自然指向新面板。代价是**改动面大**，
  且 `__demo` 八态夹具的路径依赖要同步核对。

**要拍的是**：`PanelSettings` 这类共用组件是留是移、夹具路径要不要跟改。
**这两件事定了，方案本身就定了。**

## 2026-10-13 实现记录

删掉旧面板本身只有几行，**真正花时间的是它带出来的东西**——
这才是这张票从 2026-10-09 挂到现在的原因（「改个 `url` 而已」的读法
会以为它是个小票）：

1. **窗口控制没有位置**。纸面板的四行骨架（档位 / 归属 / 正文 / 动作）
   里没有头部，而窗口是 `decorations: false`。控制键挂在**撕口那条上沿**，
   那一行同时是 `data-tauri-drag-region`——纸面板也没有别的抓手。
   旧的 `WinCtl` 零改动复用。
2. **设置界面是旧面板内的一块互斥主区**，不是独立窗口。
   整块搬进新面板，底色换成 `--cs-paper` 中性白（设计规范 §1：
   设置页不参与纸叙事）。`{#if}` 换而不是叠层，撕口带与窗口键留在外面。
3. **档位是前端第二份真值**（破硬约束第 5 条）：`$state` + `?tier=` 探针，
   一个 `invoke` 都没有。现已走 `get_tier` / `set_tier`，且**采信 Rust 回传值**，
   失败时回读真值——与 `PanelSettings.changeTier` 同一套策略。
   ⚠ 这两处原本是**同一个判断的两份实现**，写成两遍必然分叉。
4. **`readout` 没有接收方**：Rust 侧观察循环一直在 emit，前端一个
   `listen` 都没有，正文区永远停在「对方说完话，这里才落笔」。
   `menu:settings` 同理——旧面板在听，删掉它就漏掉，表现为托盘点得动、
   面板弹出来了、设置区却没开。
