# 62: 设置屏三处违反一致性——假架构文案 / 原生样式 tag / 勾选画成了勾选框

**What to fix:** 用户 2026-10-18 三条：
「1. 为何是主模型、备用模型？2. 发送档位按钮、配置tag都还是原生样式？
你是根本不管我的要求是吧？3. 勾选为何要放到前面？不应该和主页档位统一的呈现选中方式？」

**Status:** done · 2026-10-18 · 验收项 **9/9**

## ① 「主模型 / 备用模型」是我编的，而且在界面上说了一个**假架构**

真名在 `crates/reason/src/transport.rs:127`：

```rust
Self::Decision => "决策模型",
Self::Llm      => "回复模型",
```

⇒ 真实结构是**一条消息走两段流水线**（`Reasoner::judge` 判断意图 +
`draft`/`rank` 起草排序），两段**每条消息都跑**（A×2 + B×1），
**不存在「主失败才启用备」**。

写成「主 / 备」会让人以为配了备模型就不用管主模型 ⇒ **这个误解直接导致配错**。
而 demo 夹具是排版评审的基准，名字错了等于把错的架构钉在每一张出图上。

⇒ 两个夹具组名改回 `决策模型` / `回复模型`，与 `label()` 逐字相同，
并把这条写进夹具注释（免得下一个人又"优化"回去）。

## ② 「配置 tag 还是原生样式」= `.cs-badge.miss` 那圈 `inset 1px` 描边

那一圈是 **Web 表单控件的皮肤**：同屏按钮是撕边纸片
（`border-image: strip.png` + 落影），而它孤零零顶着个细灰框
⇒ 读成「另一个应用塞进来的」。

⇒ 两支改成**同底不同深浅**（`.ok` 12% / `.miss` 20% 墨洗），
差别用混比说，不用边框说。「未配置」更重，因为它**需要动作**。

⚠ 顺带记一条历史：那一支原先写的是 `var(--cs-line)`，
而 `--cs-line` **全仓从未定义**（刻线那支叫 `--cs-rule`）——
引用不存在的属性 ⇒ 该值计算时 invalid ⇒ 整条 `box-shadow` 作废
⇒ 那圈描边**从来没渲染出来过**，而 svelte-check / eslint 都不报。
**「名字看起来合理」不等于它存在**，这一类缺口门禁抓不到。

## ③ 「勾选为何要放到前面」= 我把**盖章**画成了**勾选框**

我上一版（票 61）给芯片加了 `padding-left: 30px` 把勾排成左侧一列，
想的是「像单选框」。用户的判词是对的：那是**两种交互隐喻**——
勾选框列表读作「从这里挑一个」，盖章读作「已经盖了这一颗」。
同一个「发送档位」不能两套。

⇒ 撤掉 `padding-left`，勾**压在标签上**（`left: 1px`，`top: 50%`），
与主面板 `.cs-tick` 的笔心对齐关系一致。

## ② 之二：「发送档位按钮还是原生样式」——它和主面板**本来就是两套 UI**

查出来这一条最严重：`SegSlider` 的红勾是**我在 2026-10-18 当天摘掉的**，
而摘它的理由原文是：

> 「同一屏里主面板用的是红铅笔勾，两处选中态读成两套 UI」
> ⇒ **方向对，尺子用错了地方**

它量的是 **56×34 原尺寸盖 12.48px 小字**，于是我把勾整个删了，
只剩一个 12% 墨洗 + 1px 描边的药丸——
**结果「同一个发送档位」在主面板是盖章、在设置屏是描边药丸**，
正是「不统一」的本体。

⇒ 勾**当天加回来**：缩到 **18×10.9**（保持 `TICK_VIEW` 的 56:34），
压在药丸左端内侧、只碰第一个字的一角。
药丸本身仍由 GSAP 动 `left/width`，勾在药丸**内部**绝对定位
⇒ 滑块走到哪勾就跟到哪，不需要第二套状态。

⚠ 22×13.4 那档试过并退回：仍吞掉「只填入」的半个「只」字
（票 57 拍的就是这件事，这次是复现而不是新问题）。

## 三处红勾现在的尺寸（**方式统一，尺寸按容器**）

| 位置 | 尺寸 | 容器 | 说明 |
|---|---|---|---|
| 主面板档位行 `.cs-tick` | 60×40 取景框 | 20px 上下的大字 | 原样未动 |
| 设置屏厂商芯片 | 30×18 | 12.5px 字 | 压第一个字的一角 |
| `SegSlider` 药丸 | 18×10.9 | 12.48px 字 | 再压就吞字 |

⚠ **方式必须一致，尺寸不必一致**——票 57 的结论要带着条件用：
「勾没有一个能用的尺寸」是在 **56×34 压 12.48px 小字**那一格上量的，
不是对所有容器成立。
