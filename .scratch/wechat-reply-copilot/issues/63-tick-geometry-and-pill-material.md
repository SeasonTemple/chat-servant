# 63: 勾的位置与药丸的材质——两处「我自己发挥」被真机裁图打回

**What to fix:** 用户 2026-10-18 连着三轮贴**真机裁图**打回：
「这三个组件符合统一设计吗？」「为什么勾选在文字最前面？你是傻子？」
「这三个按钮的样式一致？发送档位你还是不觉得有问题是吧？」

**Status:** done · 2026-10-18 · 验收项 **10/10**

## ① 勾的位置不是「设计」出来的，是**量**出来的

前两轮我都在凭印象摆勾（先排成左侧勾选框列、再缩成 18×10.9 压第一字），
用户两次都判「放在文字最前面」不对。

⇒ 量主面板（`target/probe/main-tick-geom.mjs`，Chromium 380×560）：

| | 左 | 右 | 宽/高 |
|---|---|---|---|
| `.cs-pick-name` 字 | 88.3 | 133.7 | 45.5 / **14.85** |
| `.cs-tick` 勾 | **73** | 127.4 | **54.4** / **33** |

换算成字号（14.85）：

```
勾宽 = 3.66em   勾高 = 2.22em   勾心 − 字心 = −0.73em
```

⇒ **勾比整串字还宽，横跨着盖上去**，心偏左四分之一个字。
这就是「盖章」。我把关系抄成三个 em 常量（`.cs-chip-ring` 与
`.cs-pill-tick` 共用同一组），谁改字号比例自动跟着变。

### ⭐ 票 57「勾吞字」的真正解法在这一格

它当时用 `TICK_VIEW` **原尺寸 56×34**——那个高（34）**比整组（31.7）还高**，
所以必然全盖。问题不是「勾盖字」，是「**勾比容器高**」。
按容器重算后（药丸内容高 27.6 ⇒ 勾 45.7×27.7）两者不再打架，
**当天摘掉的勾当天就加回来了**。

## ② 药丸是那一屏唯一的 Web 控件

`target/probe/set-geom.mjs` 实测：

| | `.cs-btn-mini`（按钮族） | `.cs-pill`（改前） |
|---|---|---|
| `border-image` | `strip.png` | **none** |
| `border-top-width` | 10px | 0 |
| `box-shadow` | none | **`inset 0 0 0 1px`** |
| 高 | 46 | 27.7 |

用户红框圈的就是那个圆角描边块。⇒ 药丸改为**撕边纸片**：
同一张 `strip.png`、同一个 `slice 32 / width 10px`、
落影用 `drop-shadow`（`box-shadow` 会从撕口透明区漏出矩形直边）。

### ⚠ 撕边要求**落位外扩**，于是 `slideTo` 多了一个 `bleed`

原来 `slideTo` 写 `left = offsetLeft; width = offsetWidth`——药丸与激活项
**逐像素重合**，那是「描边药丸」这个形状的前提。
换成撕边后撕掉的 10px 就会直接啃在文字上（「只填入」只剩半只「只」，实测）。
⇒ `slideTo(pick, duration, bleed)`：`left = offsetLeft - bleed`、
`width = offsetWidth + bleed * 2`，内衬盒仍与激活项重合、撕边落在盒外。

⚠ **同一个 `10` 出现在三处，必须一起改**：
`.cs-pill` 的 `border-width`、`slideTo(..., 10)`、`.cs-seg-btn` 的左右 padding。
少改任何一处 ⇒ 撕边啃字（第一版只改了前两处，就啃了）。

## ③ 三个动作按钮：几何**本来就一致**，差别只有「删除」站的位置

实测同一行三颗：宽 88.4 / 76.5 / 65（差异只是文字长短），
高**全是 46**、圆角**全是 5px**、`border-image` 全是 `strip.png`、
间距**都是 5.6**、基线**齐**（top 都是 190）。

真正的问题：那一抹红**被两个中性按钮夹在正中间**。
⇒ 红不能撤（硬约束第 4 条，删除是唯一不可逆的），
但「用不用红」和「站在哪」是两件事 ⇒ `margin-left: auto` 推到行尾，
这一行读成**两个维护动作 + 一个拿走东西的动作**。

## ④ badge 两轮改法都是错的

① `inset 1px --cs-edge` 描边（Web 表单框）
② 12% / 20% 墨洗「同底不同深浅」——**仍然是一个灰底小块**，形状没变

⇒ 第三轮**去掉底色**：它是组标题行右端的一个**注记**，
和主面板那些说明是同一种东西。状态靠 `已配置`（墨 600）/
`未配置`（铅笔灰 400）的**字**说，不靠一块底。
