# 65: 「勾心 −0.73em」是一个样本的常量，被我当成了关系

**What to fix:** 票 63 把主面板量到的三个 em 常量（`3.66em / 2.22em / −0.73em`）
抄给设置屏的芯片与药丸，说「谁改字号比例自动跟着变」。
**真机实拍证明：那个 −0.73em 根本不是关系，是一个常量。**

**Status:** done · 2026-10-18 · 验收项 **8/8**

## 一句话的病根

**锚点本来就对，是我额外加的偏移把它推歪的。**

`target/probe/main-tick-anchor.mjs`（Chromium 380×560）实测主面板：

```
.cs-markbox 宽 81，中心与字心偏差 0.0      ← 锚点就是字心
勾心 − 字心 = −11.1px（改之前）           ← 全是 --mx: 8px 加基准项推的
墨 76.3→123.6 / 字 88.3→133.7 ⇒ 左溢出 12，右还差 10 没盖到
```

⇒ 「盖章盖在字上」这条定案**从来没成立过**，成立的是「盖在字的左边」。
而票 63 把这个左偏量按字号折算成 `−0.73em` 抄走，**等于把 bug 抄了一遍还写成了规范**。

## 真机 + 量具复测：那枚偏移不随标签长度变

`target/probe/chip-tick-geom.mjs`，设置屏三个 SegSlider：

| 标签 | 字宽 | 勾心 − 字心 | 换算成字宽的倍数 |
|---|---|---|---|
| 只填入 | 37.5 | −12.9px | **−0.34** |
| 退出 | 25.0 | −12.7px | **−0.51** |
| 勾 | 12.5 | −12.9px | **−1.04** ← 勾整个掉到字的左边 |

三行的 **px 几乎一样**（偏移是常量），**倍数却从 0.34 跑到 1.04**。
一字标签上那枚勾**根本没碰到那个字**——用户读成「勾选在文字最前面」，
说的就是它，而它正是从主面板抄来的。

## 第二条病：同一屏里同一个记号有**两种尺寸**

`.cs-pill-tick` 与 `.cs-chip-ring` 写的是同一行 `3.66em / 2.22em`，
而 `em` 各按**自己继承到的字号**解算：

| | 继承到的字号 | 取景框 |
|---|---|---|
| 药丸（`.cs-pill`） | **16px**（`.cs-seg` 的 1rem） | 58.5 × 35.5 |
| 芯片（`.cs-btn-mini`） | 11.5px | 42.1 × 25.5 |

**同一屏差 1.39 倍。** ⇒ 尺寸改走 `--cs-stamp-w`（`app.css`，唯一出处）。
高度由 `56 : 34` 的取景框比例在消费处算出，**不另写第二个数**。

## 定案

1. **勾心 = 字心**，三处统一。主面板 `--mx: 8px → 0`（变量保留：三条
   `[data-*]` 分支的 `margin-left` 还在引用它，删掉会让它们直接失效）。
2. **尺寸取 `--cs-stamp-w: 44px`**（取景框宽，墨宽 = 44 × 0.848 = **37.3**
   ≈「只填入」的字宽 37.5 ⇒ 正好盖满整串字）。

## 实测对照（改前 → 改后）

| | 勾心 − 字心 | 取景框 |
|---|---|---|
| 设置屏三处 | −12.7 ~ **−12.9px** | 58.5 / **44** |
| 改后 | **−0.7 ~ −1.0px** | 统一 **44 × 26.7** |
| 主面板 | −11.1px | — |
| 改后 | **−0.3px**，墨左溢 −1.2 / 右溢 +0.7 | 不变 |

## ⚠ 方法论留档

**照抄一个样本 = 把巧合当规范。**

票 63 的推理链是「量主面板 → 折算成 em → 换字号自动成立」。
每一步单看都对，**但前提是那个量本身与标签长度无关**——
而我从来没验过那一步，因为**量的时候只有一个三字标签**。

⇒ 量「相对位置」这类量，必须**跨至少两个样本**（这里 1 / 2 / 3 字）
   再看那个比值稳不稳定；比值不稳 ⇒ 你量的不是关系，是一个巧合。
   ⚠ 同族：本票里 `--cs-stamp-w` 的来历是「墨宽 ≈ 三字标签的字宽」，
     一字标签上墨是字的 3 倍——这是**已知取舍**（印章固定大小，
     宁可大到压出字外，也不能小到读不出是勾），不是没看见。
