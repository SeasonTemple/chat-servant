## 触发它的那个问题

用户问「那个 12 张合成语料是否涉及隐私」。
⇒ **那 12 张本身干净**（三重证据见下），但查的过程里撞出两个更大的洞。

## 先把结论钉住：合成语料不涉及隐私

| 证据 | 内容 |
|---|---|
| 数据源 | `gen_corpus.py` 的 `POOL` 是**硬编码的通用办公句**，逐字在脚本里，无一条来自真人会话 |
| 易被误认真 | 「Q3 的预算 number」「2024Q1 报告.pdf」「500 了 retry 一次」里的数字是**编的**，不指向真实项目/金额/文件名 |
| 图内容 | docstring 明写「不做气泡尾巴 / 头像 / 时间戳」，源码只画圆角矩形 + 文字 ⇒ 无「谁在何时说了什么」的标识 |
| 进不了仓库 | `git check-ignore -v` 实测三项全部忽略（`.gitignore:1 /target`） |

## ⚠ 缺口 A：截图闸只判路径，不判内容

`.githooks/pre-commit` 第二道闸的全部判据：

```
target/* | */target/* | probe-out/* | */probe-out/* | .scratch/tmp-probe/*
*/probe/*.png | */probe/*.jpg | */probe/*.jpeg | */probe/*.bmp
```

**全是路径模式。** ⇒ 把一张聊天截图拖进仓库根、命名 `shot.png`，
**闸门不拦**，它会进 git 历史。而本仓公开在 GitHub 上。

⚠ 已实证「路径判据」的盲区不是假想：合法资产 `ui/static/probe-sheet.png`
就因为「`probe` 是文件名前缀、不是目录」而没被 `*/probe/*.png` 匹配到。
⚠ 顺带：这个名字本身有误导性，它是**纸的纹理**（已看图确认：空白牛皮纸，
无任何文字），不是探针截图 ⇒ 建议改名 `paper-sheet.png`。
**改名会牵到引用它的代码，本票不动手。**

## ⚠ 缺口 B：`.gitignore` 只管文件，文字那条路是敞开的

**已发生的实证**：合成语料的图被 ignore 了，但**提交信息里写了语料原句**
（「retry 一**次**」→「retry **—**次」，commit `466d275`）⇒ 那段文字
已经进了 git 历史。

这一条**目前还安全**，只因为那些句子是编的。
⚠ **将来若有人往 `POOL` 里放真实业务内容**（"XX 项目预算是 300 万"），
`.gitignore` 一行都拦不住——**它管文件，不管 commit message 与源码字面量**。
而第二道闸按路径判，恰恰也管不到「文字形式的聊天内容」。

⇒ **同一条边界（硬约束第 3 条）的两个漏法，一个管文件、一个漏文字。**

## ⚠ 前置二：凭据闸自身没有任何守卫

`grep -n 'githooks|pre-commit' scripts/gate.ps1` ⇒ **零命中**。

凭据闸是硬约束第 7 条的最后一道防线，而它整个消失或被改坏，
**门禁一声不吭**。⚠ 这与本票的两个缺口是同一个病：
**守卫本身没有守卫**。

⚠ 本轮已修的只是它的一个具体失效（豁免标记让文件自己豁免自己，
commit `9cf53f9`），**「闸门是否存在」这一层仍然没人守**。

⇒ 候选判据：`.githooks/pre-commit` 存在 ∧ 含凭据 `pattern` ∧ 含两段式 marker。
⚠ 但**新增门禁步要四处一起改**（`gate.ps1` + `ci.yml` + `release.yml` +
`AGENTS.md` + `CONTRIBUTING.md`）——本仓踩过「两套门禁各说各话」，
所以这件事不该顺手做。

## 两条缺口的修法难度不同，要分开对待

| 缺口 | 可否机器判 | 修法 | 难度 |
|---|---|---|---|
| A 图片落到仓库任意位置 | ✅ 可以 | 全局拦图片扩展名 + 7 条例外清单 + 按扩展名而非目录名判 | 低 |
| B 真实聊天内容进提交信息/源码字面量 | ❌ **没法可靠判** | 只能靠**流程**：写进 `AGENTS.md`「提交信息与源码里不写真实聊天内容」，靠 review | 高，且不可自动化 |

⚠ ⚠ **别把 B 写成一条机器守卫。** 判据只能是「这段文字像不像真人聊天内容」，
而那正是本仓 AGENTS.md 明令禁止的形态：**「看起来没达标就换判据」比没判据更坏**，
因为它会在仓库里留下一条永远绿着的假守卫。
⇒ **B 的正确形态是流程要求，不是守卫**——写下来、靠 review，不假装能自动。
