## 实测（2026-10-21，真机帧，`target/probe/name/`，不入库）

同一块真机像素（会话名那一行的带子），**只改带高**，**放大 2×**，两个引擎各跑一遍：

| 带高 | PP-OCR（生产默认） | WinRT（回退） |
|---|---|---|
| 40px | 1 行 / 2 字 ✓ | 0 行 ✗ |
| 60px | 1 行 / 2 字 ✓ | 0 行 ✗ |
| **72px（生产值）** | 1 行 / 2 字 ✓ | **0 行 ✗** |
| 100px | 1 行 / 2 字 ✓ | 1 行 / **1 字** ✗（只读出半个名字） |
| 140px | 1 行 / 2 字 ✓ | 0 行 ✗（**更高反而更差**） |
| 200px | 1 行 / 2 字 ✓ | 1 行 / 2 字 ✓ |

⇒ **PP-OCR 在 40~200px 全稳**；**WinRT 要 200px 才稳，140px 反而读不到**。

⚠ 另一组实测（3 帧 × 2 种重采样，`target/probe/name/analyze-name.py`）：

```text
PP-OCR：换重采样后 3 帧全部「结果不变」（编辑距离 0）
WinRT ：换重采样后 3 帧全部「结果不变」（两种都读不到，0 行）
```

⇒ **改这条路的重采样方式，今天零收益**（PP-OCR 逐字相同、WinRT 两种都读不到）。

## ⚠ 原来那张表不可复现，而且它的**解释是错的**

`PEER_NAME_BAND_H` 的文档原先写着「2026-10-07 实测：40px 0 行 / 60px 1 行 / 100px 1 行」。
今天按同样方法重测，**那张表对不上**（当年的原始带子已不可考）⇒ 只能订正，不能还原。

⇒ 同时纠正一个**错误的解释**：原文档写
「带子太窄、里面又只有一个小字时 OCR 不收——它需要周围有内容」。
实测那是 **WinRT 的毛病**：PP-OCR 在 40px 上照样稳定读出，**它根本不挑余量**
⇒ 原来把**一个引擎的毛病**当成了通用规律，还写进了代码注释。

## 影响面：有限，而且**闸不受影响**

**身份闸比的是像素指纹，不是名字**：
`perceive::identity::HeaderPrint::is_same` 比的是**二值墨迹掩码的 Dice**
⇒ 名字读不到 / 读错，**既不会锁错人，也不会不推理**。

受影响的只有两处：
- 面板标题空；
- `TurnContext.peer` 空 ⇒ 提示词里没有对方名。

## 为什么**不**加高带子去修

- **加高不是单调变好**：WinRT 在 140px 反而读不到，要 200px 才稳；
- 带子按 `chat.y1` 截断，**加高会把别的内容一起带进来** ⇒ 读到的第一行可能不是名字；
- 代价落在**回退路径**上，而回退路径本身是**降级档**
  （默认引擎 PP-OCR 一切正常）。

⇒ 缺口**记账**，不当成「顺手能修的 bug」。

## 这一票实际改了什么

1. **`ui/src-tauri/src/watch.rs::PEER_NAME_BAND_H` 文档**：
   换成 2026-10-21 的**两引擎**实测表，写明原 2026-10-07 表**不可复现**，
   并说明 72 为什么保留（PP-OCR 在它上面稳定；WinRT 的缺口另记）。
2. **`peer_name_from_header`**：**倍数仍固定 2×**（11px 小字必须放大），
   但**重采样方式改为跟引擎走**（`ocr::engine().resample()`）
   ⇒ 实测**零行为变化**，改的是「别让这条长出第二份会漂的配方」。
3. **守卫 `the_watch_layer_does_not_hand_roll_the_ocr_recipe` 扩展**：
   读会话名那条路也不许出现 `upscaled_nearest` / `upscaled_bilinear` / `Resample::`，
   且**必须**向引擎要配方；并加一条「函数体找不到 ⇒ 报红」的自检
   （免得守卫自己空转）。
   ⚠ **两条负向自证都实测会红**：
   - 注入 `upscaled_nearest` ⇒ 红（`watch.rs:3830`）；
   - 注入 `Resample::Nearest` ⇒ 红（`watch.rs:3834`）。
4. **文档**：本票 + `docs/HANDOFF.md` §4.12 + `docs/adr/0006-ocr-engine-evaluation.md`
   追加一节。
