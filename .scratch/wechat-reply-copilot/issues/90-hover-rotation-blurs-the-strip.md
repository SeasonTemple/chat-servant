# 90: 悬停时那条候选「变糊」——0.5° 旋转让合成层重采样

**Status:** open · **候选 ① 已落地，6/7 项完成，等真机那一眼**（2026-11-01：去掉 `.cs-act:hover, .cs-act:focus-visible` 的 `rotate(-0.5deg)`，保留 `translateY(-2px)` + `drop-shadow(0 8px 16px rgb(24 18 10 / 0.26))`；同步 `docs/设计规范.md`；`probe-act-states.mjs` @2x 复测锐度方差从 −44.9% 回到 +0.12%）

## 一、现象

用户在候选行上看到**质感不一致**：放大自己发的截图后，
有一条候选明显比旁边那条「糊」。

## 二、根因：**那 0.5° 的旋转**

`.cs-act:hover` 给的是：

```css
.cs-act:hover { transform: translateY(-2px) rotate(-0.5deg); }
```

⚠ Chromium 对**带 transform 的元素**会提成**独立合成层** ⇒
文字与撕边纹理被**重采样** ⇒ 那一行看上去比别的行软。

⇒ **糊的不是样式，是渲染。**

## 三、实测（`ui/scripts/probe-act-states.mjs`，deviceScaleFactor=2）

量的是**同一条行**在各种写法下的图，指标是
「边缘强度（top 1% 梯度均值）」与「拉普拉斯方差」：

| 写法 | 边缘强度 | 锐度方差 | 相对静息 |
|---|---|---|---|
| 静息 | 107.80 | 1838.7 | — |
| **悬停·生产（+2px 转 0.5°）** | 90.68 | **1049.7** | **−15.9% / −42.9%** |
| 悬停·只上抬（`translateY(-2px)`） | 107.80 | **1844.2** | 0% / **+0.3%** |
| 悬停·转 + 文字反向转回来 | 90.80 | 1033.1 | −15.8% / −43.8% |
| 点过（`:disabled`，只收影） | 107.80 | 1833.1 | 0% / −0.3% |

Auto 档同一条现象：静息 107.82 / 2076.3 ⇒ 悬停 93.39 / 1471.8（−29.1%）。

### 三条结论

1. **糊的唯一来源是旋转。** 整数位移（`translateY(-2px)`）**像素对齐** ⇒ 不重采样 ⇒ 锐度不掉（甚至略升，因为影更深带来更多边缘）。
2. **「文字反向转回来」没用。** 文字被光栅进**父层**，父层一旋转就重采样；子元素再转只是**多叠一次**。
3. **`:disabled` 收影不影响锐度**（−0.3%）⇒ 「点过那条不像纸片」是**影**的问题，不是糊的问题。

## 四、为什么这一票**开着**：去旋转 = 改设计

`docs/设计规范.md` §候选行按钮族表第 434 行**明写**：

```
| 悬停 | hover 墨 7% | `translateY(-2px) rotate(-0.5deg)` + 影加深（**拿起来**） |
```

⇒ 0.5° 的倾斜是**规范里的写法**，不是随手写的参数
⇒ 去掉它 = 改设计 ⇒ **要用户一句话**（票 89/88 都是这么处理的）。

### 修法候选

| | 改法 | 代价 |
|---|---|---|
| ① | 去 `rotate`，保留 `translateY(-2px)` + 影加深 | 少一点「斜着拿起来」的姿态感；**锐度实测不掉** |
| ② | 保留旋转，接受悬停时那一行偏软 | 现状 |
| ③ | 换别的「拿起来」提示（影再深 + 提亮） | 要重新出图核对 |

## 六、顺带纠正的一条**上轮错误结论**

上一轮我回答用户「两条都是纸片，差别在 hover」——**这是错的**。

面板上的候选分**两个元素**渲染：

| 谁 | 元素 | 材质 |
|---|---|---|
| **第一条候选（推荐）** | `.cs-draft-lead`（在 `.cs-draft` 正文位里） | **正文**：21px 仿宋墨色，**无撕边无影** |
| **第 2 条起（备选）** | `.cs-act`（在 `.cs-actions` 动作区里） | **撕边纸片**：`border-image: url('/strip.png')` + 两层影 |

⇒ **用户看得没错**：第一条本来就不是纸片。
⇒ 这是**票 68 的设计**（正文 = 第一条候选，正文保留大字、可选中复制；动作区从第 2 条起），
  规范 §4.2b 已写明「**两者材质不同是有意的**」。
⇒ **我上轮量错了对象**：按 `.cs-act` 取样 ⇒ 只量到备选 ⇒ 得出「两条都是纸片」。
  ⇒ 教训与「量具量的是谁」同族：**取样前先问「用户说的那个东西是哪个元素」**。

## 七、2026-10-24 用户判定：**旋转不是重点**

用户对这张对照板的反应是：「旋转是重点吗？目前如图那么明显的差异？**不才是问题？**」

⇒ 他指的不是 0.5° 带来的那点锐度差，而是**图里最扎眼的那件事**：
第一条候选是**纯文字**、其余是**撕边纸条** ⇒ 两种材质。

⇒ **本票降级**，本轮不动旋转；那件事在**票 92** 里改掉了
（第一条候选也改成撕边纸条 ⇒ 材质统一）。

⚠ 记在这里是为了以后别把它当成「已排除的次要项」：
**这条的实测结论仍然成立**（旋转 ⇒ 锐度方差 −42.9%），
只是**优先级**排在材质之后。
