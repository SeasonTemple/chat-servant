# 91: Auto 档正文最后一行被**横切一半**

**Status:** done（2026-10-24 已修：正文区补上与候选区**同一套**的底部渐隐 + 量具新增判据「正文溢出渐隐」⇒ 反向自证：改废那条规则 ⇒ 量具红 5 条）

## 一、现象

`?demo=1&state=auto` 的整张纸截图（`target/probe/panel-type/sheet-auto.png`）：
正文的最后一行「…到 3。你再帮我看一眼」**被横着切掉一半**——
上半行的字形在，下半行没了。

## 二、根因：**滚动容器按行裁切**

票 88（2026-10-24 推）把 `.cs-draft` 改成**滚动容器**：

```css
.cs-draft { flex: 0 1 auto; min-height: 0; overflow-y: auto; }
```

手工档没有警告行 ⇒ 正文高度够 ⇒ 看不出问题。
**Auto 档多了一行红字警告**（「「自动发送」档：按下去就发出去了，收不回来。」）
⇒ 正文可用高度少 ⇒ 滚动容器**从中间切掉一行**。

## 三、为什么难看

切一半读成「**这张纸坏了**」，不是「下面还有」——
这与 `.cs-actions` 当年的**横向切半**是同一个道理
（票 44 的注释里写着同一个判断：「一张纸齐腰断开，读出来是『这张纸坏了』」）。

⚠ 但两者语义不同：候选区切半 ⇒ 「下面还有更多候选」（滚动条还在，信号明确）；
正文切半 ⇒ 「这句话被弄断了」（没有任何提示说它还能滚）。

## 四、量到的事实

- 手工档：正文 6 行**完整**显示，末行完整。
- Auto 档：正文最后一行**切半**。
- 候选组与档位行**没有**出纸（票 88 的量具仍绿）⇒ **只有正文这一处**。

## 五、修法候选（都还没动）

| | 改法 | 说明 |
|---|---|---|
| ① | 正文区高度**按行取整** | 行高 = 21px × 1.5 = **31.5px** ⇒ 高度取 31.5 的整数倍 ⇒ 要重算票 44/88 的预算 |
| ② | 正文底部加**渐隐 mask** | 与 `.cs-actions[data-more='true']` 同款；但候选区的渐隐读成「下面还有」，正文的渐隐会被读成「字淡了」 ⇒ 语义不同，要重新想 |
| ③ | 警告行**不占正文高度** | 例如叠在候选组上方（它现在就在候选组上方，但吃的是**正文**的高度）⇒ 要重量具 |
| ④ | 先不动 | 真机上的草稿通常只有一两行，够放；只有长草稿才撞上 |

## 六、验收项

- [x] 现象定位到**滚动容器的按行裁切**（不是素材、不是折叠线）
- [x] 手工档不撞、Auto 档撞 ⇒ 判据是「**多了那行警告**」
- [x] 证据图：`target/probe/panel-type/sheet-auto.png`（gitignored）
- [ ] **修法定下来**（①~④ 或新方案）
- [ ] 量具补一档：`ui/static/budget.html` 的 STATES 里加 `auto-longdraft`（长草稿 + Auto 档）
- [ ] 改完复跑量具 + 真机复验

## 七、为什么**现在不动**

修法 ①②③ 都要动**票 44 / 88 的高度预算**（那两张票的验收项都是「档位格不许出纸」）
⇒ 改之前得重算 ⇒ 属于**要人拍板的那一类**（用户在他那台 160% DPI 的机器上看效果）。
⇒ 本票只把现象与量到的事实记下来，不偷跑一个改法。

## 八、2026-10-24 已修（票 92 顺带做掉）

**修法**：正文区（`.cs-draft`）补上与候选区**同一套**的底部渐隐
（`.cs-draft[data-more='true']` ⇒ `mask-image: linear-gradient(...)`）⇒
被切的那一行**化掉**而不是硬切 ⇒ 读成「纸往下延伸」。

**为什么是「同一套」而不是另发明一种**：
候选区早就处理过同一个问题（横向切半 ⇒ 渐隐）⇒ 同一个产品里两种滚动的做法必须相同。

**量具**：新增判据「**正文溢出渐隐**」⇒ 量具 42 条判据 ALL GREEN。
**反向自证**：把那条规则改废 ⇒ 量具立刻红 **5 条**（五个状态各一条）⇒ 守卫真会响。

⚠ 顺带记一件事：本票的现象在**票 92 的材质改造之后更明显**——
撕边让第一条候选高 32px ⇒ 长草稿更早撞上裁切 ⇒ 渐隐因此从「锦上添花」变成「必须有」。
