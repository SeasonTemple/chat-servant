# v0.1.0

首个公开版本。Windows 单机桌面程序，观察你自己的微信单聊窗口，
给出候选回复，**默认只填入、不发送**。

## 中文

首个公开版本，主要内容：

- **窗口级捕获 + 本地离线 OCR**（WGC + Windows.Media.Ocr，PP-OCRv4 可选）。
  不 hook、不注入、不读对方数据库、不解密、不碰对方进程内存。
- **感知层**把 OCR 框归类成「我方 / 对方 / 噪声」，并有**会话身份闸**：
  第一帧锁定会话，之后只对锁定的那一个动手，锁错可手动重锁。
- **推理层**（`crates/reason`）是全链路唯一出网的阶段。静默期零调用——
  十分钟没人说话就是十分钟零 token。
- **发送分三档**：`Manual`（只填入）→ `Confirm`（二次确认后发送）→ `Auto`。
  默认最低档，升档显式、可回退、会话结束自动回落。**档位由 Rust 侧持有**，
  界面只能请求改。
  ⚠ **这一行只描述 v0.1.0 当时的形态。** 2026-10-13（v0.1.0 之后）
  第三档 `Auto`（填入即发、不打断）已**整档取消**，现在只有前两档。
  理由见 `docs/设计规范.md` §10 第 3b 条；守卫是
  `crates/core/src/dispatch.rs` 的 `the_tier_set_is_exactly_two_and_named`。
- **API key 只从 Windows 凭据管理器或环境变量读**，不落普通文件、不进日志，
  所有对外文本脱敏。
- **截图不落盘**。帧常驻内存，不写盘、不进日志、不上传；唯一例外是显式调试
  命令 `cargo xtask probe` 写入 `target/probe/`，且会明确提示。
- **不碰钱**。转账、红包、收款相关元素一律不触碰。

界面是 Tauri 2 + Svelte 5，Windows 独占（捕获链路无跨平台等价实现）。

已知限制：

- 仅支持 Windows；仅支持微信**单聊**。
- 黄金测试夹具来自真实会话，**不入仓库**，相关用例在 CI 上是**跳过**而非通过。
- 需要 Windows 10 1803+（WGC）与 Windows 11 更稳。

## English

First public release. A single-machine Windows desktop app that observes **your
own** WeChat 1:1 chat window, proposes replies, and **fills them in without
sending by default**.

What is in it:

- **Window-level capture + local offline OCR** (WGC + `Windows.Media.Ocr`,
  with PP-OCRv4 optional). No hooking, no injection, no reading the other
  party's database, no decryption, no touching their process memory.
- **A perception layer** classifies OCR boxes into speaker / non-speaker /
  noise, behind a **session identity gate**: the first frame locks the
  conversation, and the app only ever acts on that locked one. Re-lockable.
- **The reason stage** (`crates/reason`) is the only stage that reaches the
  network. It makes **zero calls while the conversation is silent** — ten
  quiet minutes is ten minutes of zero tokens.
- **Sending is tiered**: `Manual` (fill in only) → `Confirm` (send after a
  second confirmation) → `Auto`. The default is the lowest tier; raising it is
  explicit, reversible, and reverts automatically at session end. **The tier
  is held in Rust** — the UI can only request a change, never assert one.
- **API keys are read only from Windows Credential Manager or environment
  variables**, never written to ordinary files or logs; all outbound text is
  redacted.
- **Frames never touch disk.** They stay in memory — not written, not logged,
  not uploaded. The single exception is the explicit debug command
  `cargo xtask probe`, which writes to `target/probe/` and says so.
- **It never touches money.** Transfer, red-packet and payment UI elements are
  out of scope entirely.

Built with Tauri 2 + Svelte 5. Windows-only by construction — the capture path
has no cross-platform equivalent.

Known limitations:

- Windows only; WeChat **1:1** conversations only.
- Golden-test fixtures are derived from real conversations and are therefore
  **not in the repository**; the tests that use them **skip** on CI rather than
  pass. A green CI run does not mean the pixel-level baselines were verified.
- Requires Windows 10 1803+ (WGC); Windows 11 works better.
