# v0.2.0 (Beta 1)

## 中文

首个功能完整的 Beta 预发布版（自 `v0.1.2` 以来共 170+ 次提交），完整打通微信 4.0 单聊「捕获 → 本地离线 PP-OCRv6 → 多会话分桶与身份闸 → Jev 五维决策 → 候选起草 → 无感自动发送与回声抑制」闭环：

- **Jev 专用决策模型与思考等级配置**：
  - 原生对接 `TypeSafe (Jev)`（`/v1/systemone`，实测核准 `jev-latest` / `jev-preview`）与 `OpenRouter (Jev)`（`/api/alpha/decisions`），完整发送并解析 5 道 System-1 结构化决策问题（直面/潜台词、真实意图、核心需求、最佳行动、危险度评分）；
  - 决策模型与回复模型均支持「思考等级」（关闭/最低、低、中、高，默认关闭/最低以降低推理延迟），跨轮复用 HTTP Keep-Alive 连接池，并支持本机代理端口自动探测（10 秒缓存）与阿里 DoH 防污染解析回退。
- **无感自动发送三件套与回声抑制**：
  - **键鼠活跃期避让（`GetLastInputInfo`）**：`Auto` 档后台自动触发发送前检测系统键鼠空闲时间，用户正在打字或滑鼠标（`< 1.2s`）时自动暂缓至停手后再发；
  - **焦点与剪贴板无感还原**：自动发送完成后立即恢复用户原有的剪贴板文本，并将窗口焦点归还给发送前的前台窗口；
  - **自发回声账本（`SentRegistry`）**：登记我方刚发出的文本，下一帧 OCR 读回同句时自动识别为我方消息，彻底杜绝「自己回自己」死循环。
- **多会话分桶记忆（`SessionBucket`）与「锁定当前 / 自动跟随」双模式**：
  - 按会话头部像素指纹维护最多 16 个独立会话分桶（各自隔离 `history`、口吻样本 `mine`、已见账本 `seen` 与候选），来回切换会话时秒级恢复历史、零跨会话串味、零重复模型调用；
  - 设置页新增「会话切换」双档（`锁定当前` / `自动跟随`），支持跟随当前微信聊天窗口自动切换会话分桶。
- **端到端感知提速与全面板手绘纸张交互定稿**：
  - 观察循环轮询周期由 `1000ms` 压至 `350ms`、事件推送泵由 `300ms` 压至 `40ms`（静默期仍保持零 OCR、零模型调用）；
  - 全部候选统一为撕边纸条与手写纯数字置信度，「勾 / 圈」记号全面板同步；设置页采用纸条下拉 + 滚轮选择器（支持点击外部/Escape 关闭与 IME 安全回车提交）；支持纸外透明边鼠标穿透、右上角置顶开关、`rAF` 拖拽节流与 `2px` 暖褐铅笔滚动指示线。
- **形式化与属性测试防线**：
  - 新增 7 组 PBT 属性测试、`docs/tla/DispatchAndSessionGate.tla` 形式化规约与 Rust 内置 BFS 穷举状态空间模型检验器，以及 BDD 行为验收场景。

## English

First feature-complete Beta pre-release (170+ commits since `v0.1.2`), completing the end-to-end WeChat 4.0 single-chat loop from WGC capture and local offline PP-OCRv6 to multi-session bucketed identity gating, Jev 5-dimension System-1 decision routing, candidate drafting, and non-intrusive auto-send:

- **Jev System-1 Decision Endpoints & Thinking Effort Control**:
  - Native support for `TypeSafe (Jev)` (`/v1/systemone`, live-verified with `jev-latest` / `jev-preview`) and `OpenRouter (Jev)` (`/api/alpha/decisions`), evaluating all 5 structured System-1 questions (`literal_question`, `true_intent`, `she_needs`, `best_action`, `danger_level`);
  - Configurable reasoning effort (`Off`, `Low`, `Medium`, `High`; defaults to `Off` for minimal latency), persistent HTTP keep-alive connection pooling, automatic local proxy port detection with 10s TTL caching, and DoH fallback.
- **Non-Intrusive Auto-Send Trio & Self-Echo Suppression**:
  - **Active Input Avoidance (`GetLastInputInfo`)**: Defers background `Auto` dispatch while the user is actively typing or moving the mouse (`< 1.2s` idle) until a brief pause;
  - **Focus & Clipboard Restoration**: Saves and restores both the user's prior clipboard text and the previous foreground window focus immediately after `fill_and_send`;
  - **Self-Echo Ledger (`SentRegistry`)**: Recognizes our own dispatched lines on subsequent OCR frames so sent replies never trigger self-reply loops.
- **Multi-Session Bucketed Memory (`SessionBucket`) & Lock/Follow Modes**:
  - Maintains up to 16 isolated per-conversation memory buckets keyed by header pixel fingerprints (`history`, `mine` voice samples, `seen` ledger, and candidates), restoring state across session switches with zero cross-session leakage or redundant model calls;
  - Adds a `Lock Current` / `Auto Follow` session-switching toggle in Settings.
- **End-to-End Latency Reduction & Torn-Paper UI Finalization**:
  - Reduces the watch interval from `1000ms` to `350ms` and the event pump interval from `300ms` to `40ms` (preserving zero OCR and zero model calls during quiet periods);
  - All candidates render as torn-paper strips with handwritten numeric confidence and synchronized tick/ring marks; Settings uses paper-strip dropdown/wheel pickers with outside-click/Escape dismissal and IME-safe Enter submission; includes transparent margin clickthrough, always-on-top pin toggle, `rAF`-coalesced window dragging, and a `2px` warm-pencil scroll indicator.
- **PBT, TLA+ Model Checking & BDD Verification**:
  - Adds 7 property-based test suites, a formal TLA+ specification (`docs/tla/DispatchAndSessionGate.tla`) paired with an in-process BFS exhaustive state-space model checker, and BDD behavior verification scenarios.
