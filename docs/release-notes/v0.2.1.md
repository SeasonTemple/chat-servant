# v0.2.1 (Beta 2)

## 中文

`v0.2.0 (Beta 1)` 实机验证后的体验打磨与稳定性修复版：

- **品牌与托盘标识同步为「言侍」**：
  - 主 README 与英文 README 确立中文名 **「言侍」**（`言侍 · chat-servant` / `chat-servant · YanShi`），重写技术文档并更换全新棉纸朱砂勾横幅；
  - 托盘悬停提示与窗口标题统一精简为 `言侍`（如 `言侍 · 仅填入`）。
- **模型路由与跨会话隔离修复**：
  - 修复运行时将决策模型与起草模型拆分为独立服务商后，观察循环仍持有启动时 `ModelGroups` 克隆、导致 `Draft` 阶段误走 `Jev` 端点（HTTP 404）的问题；
  - 修复头部像素指纹在三字中文联系人名上的膨胀碰撞：将 `HeaderPrint::similarity` 改为刚体平移（`(dx, dy) ∈ {-1..=1}²`）最大 Sørensen–Dice 重合度，并在观察循环叠加 `locked_name == peer` 交叉校验，杜绝不同三字联系人间的话题串味；
  - 修复停泊关闸（`apply_gate_closed`）误清空已起草候选、导致切回原会话后面板假报「对方说完了，这轮没起草」的缺陷。
- **起草多样性与口吻回声防自激**：
  - 收紧 `SYS_DRAFT` 起草提示词，严禁三条候选同义反复，要求覆盖当前语境下不同的回复方向/表态切入点并按真实采用概率给出置信度；
  - 口吻样本池（`s.mine`）过滤掉由助手自身发出的回复（`!sent_by_us`），并约束风格提示仅参考句长与自然度、禁止机械复读单条样本的句尾口癖。
- **主面板与设置页交互细节打磨**：
  - 停泊态面板直接提供「改为锁定此会话」纸条按钮，无需再进托盘菜单重锁；
  - 当最新消息为我方发出时隐藏上方陈旧的对方引文；移除候选区上方冗余状态行与自动档重复红字；未识别会话标题精简为「未识别会话」；
  - 统一全应用手绘勾与手绘圈为明亮朱砂红（`--cs-pencil-red`），修正候选置信度槽、设置页分段滑块与底部档位行中「圈」过扁及 SVG 尺寸被 flex 盒子压缩的问题；
  - 移除设置页下拉框的滚轮切换响应，防止滚动浏览设置页面时误触切换服务商或模型。

## English

 Polish and stability update following live WeChat 4.0 verification of `v0.2.0 (Beta 1)`:

- **Brand Identity & Tray Tooltip Sync (`言侍`)**:
  - Updated `README.md` and `README.en.md` with the Chinese project name **YanShi (`言侍`)** and a new torn-cotton-paper hero banner;
  - Synchronized system tray tooltip and main window title to `言侍` (e.g. `言侍 · 仅填入`).
- **Model Routing & Cross-Session Isolation Fixes**:
  - Fixed a bug where splitting `Decision` and `Llm` model routes at runtime left the watch loop with a stale `ModelGroups` clone that routed `Draft` calls to the `Jev` endpoint (HTTP 404);
  - Replaced per-pixel 3×3 neighborhood dilation in `HeaderPrint::similarity` with rigid whole-mask translation (`(dx, dy) ∈ {-1..=1}²`) maximum Sørensen–Dice similarity and added `locked_name == peer` cross-checks, preventing fingerprint collisions across different 3-character Chinese contact names;
  - Preserved drafted candidates in `Scratch` across parked-session transitions (`apply_gate_closed` / `blank_messages`) so switching away and returning to a locked chat immediately restores its candidates without false "no draft this round" states.
- **Draft Diversity & Self-Echo Voice Filtering**:
  - Updated `SYS_DRAFT` to forbid synonymous rephrasings across the 3 candidates, requiring distinct reply intentions/angles ranked by contextual adoption probability;
  - Excluded assistant-dispatched messages (`!sent_by_us`) from the `s.mine` voice sample pool and refined the style header so occasional sentence-ending particles are not parroted on every turn.
- **Paper Panel & Settings UX Refinements**:
  - Added a direct relock action strip on the parked panel; hid stale peer quotes when the newest message is from `Me`; removed redundant status headers above candidates;
  - Unified all hand-drawn tick and ring marks to vivid cinnabar red (`--cs-pencil-red`), and fixed squashed ring aspect ratios and flex-box SVG shrinking across candidate confidence slots, Settings segmented sliders, and tier switches;
  - Removed mouse-wheel cycling from dropdown triggers in Settings to prevent accidental model/provider changes while scrolling.
